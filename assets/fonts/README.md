# Local typefaces

Cinzel (400–700), Cormorant Garamond roman (400–700) and italic (500), and Manrope (400–700). Latin WOFF2 subsets obtained from Google Fonts CSS API; unmodified font files. Each family is distributed under the SIL Open Font License included beside its font.

Source repositories: https://github.com/google/fonts/tree/main/ofl/cinzel, https://github.com/google/fonts/tree/main/ofl/cormorantgaramond, https://github.com/google/fonts/tree/main/ofl/manrope.

Fonts load with swap and local serif/sans-serif fallbacks; no third-party font request is needed at runtime.
