# Audit UI Mythics — 3 Oktober 2026

## Revisi Royal Atlas

Perombakan terbaru mengikuti permintaan suasana kerajaan: palet cokelat walnut dan emas, latar ilustrasi penuh pada landing, slideshow empat legenda, serta tipografi Cinzel dan Cormorant Garamond roman/italic. Detail karakter bertab dipertahankan agar pembaca dapat memilih topik langsung. Lingkup mencakup seluruh halaman publik: landing, arsip, detail, perbandingan, klasifikasi, peradaban, detail budaya, atlas, jurnal, dan belajar; termasuk navigasi dan dialog gambar.

Data 1.736 entri dan penilaian pada `js/scaling.js` tidak diubah. Bukti: `git diff --exit-code HEAD -- data/creatures.json data/cultures.json data/regions.json data/categories.json data/traits.json js/scaling.js` menghasilkan exit code 0. Tidak ada dependensi paket baru. Perubahan masih lokal, belum di-commit atau di-push.

## Perubahan UX

- Landing menampilkan Garuda, Kitsune, Jörmungandr, dan Barong dengan transisi silang, gerak gambar pelan, panel legenda, tombol sebelumnya/berikutnya, pilihan langsung, serta putar/jeda.
- Slideshow otomatis berganti setiap sembilan detik. Hover dan posisi di luar layar menjedakannya. Pilihan manual, navigasi keyboard, dan reduced motion menghentikan putaran otomatis sampai pengguna melanjutkan. Timer, observer, dan event listener dibersihkan saat berpindah rute.
- Gambar berikutnya didekode sebelum ditampilkan; kegagalan memuat mempertahankan gambar aktif dan memungkinkan pemilihan ulang.
- Landing memiliki strip statistik, kolom pencarian, dan tiga jalur penjelajahan menuju arsip, atlas, dan perbandingan.
- Warna, tipografi, tombol, kartu, bingkai, navigasi, dan panel seluruh halaman publik diselaraskan. Font roman tambahan sekitar 37 KB tersimpan lokal; tidak ada permintaan font eksternal saat aplikasi digunakan.
- Detail desktop menampilkan potret tetap di kiri, identitas dan tiga badge di kanan, serta enam tab di atas panel bacaan. Topik tidak lagi ditumpuk menjadi satu halaman panjang.
- Detail ponsel memakai profil ringkas dan tab sticky. Berpindah topik setelah membaca bagian bawah membawa awal topik baru ke bawah tab.
- Tab mendukung keyboard, URL, reload, perubahan bahasa, serta tautan internal ke sumber. Rincian tambahan dan dasar tiap penilaian dibuka melalui disclosure.
- Filter arsip tampil di sidebar desktop. Filter lanjutan dapat dibuka dan otomatis terbuka bila URL memuat filter tersebut.
- Direktori budaya memiliki pencarian nama/negara/kawasan, filter kawasan, persistensi URL, dan pemulihan hasil kosong.
- Animasi gambar berhenti di luar viewport atau ketika tab browser tidak aktif; reduced motion menonaktifkannya. Bingkai tujuh kelas tetap memakai CSS dan SVG tanpa gambar dekoratif raster.
- Atlas membuka daftar tradisi per kawasan melalui disclosure; daftar panjang tidak memperbesar seluruh kartu secara default. Lencana jurnal memakai simbol SVG yang konsisten.
- Fungsi perbandingan, favorit, pembelajaran, unduhan, zoom, dan pergantian bahasa tetap tersedia.

Audit visual memeriksa landing, kartu, arsip, direktori, atlas, detail, klasifikasi, jurnal, belajar, dan perbandingan. Pemeriksaan sebelumnya memperbaiki lebar input pencarian budaya; revisi ini juga memperbaiki aturan font lama yang mengecilkan label pemilih slideshow. Layout ponsel dan tablet diperiksa pada 320, 390, dan 768 px.

Sumber bukti yang dapat dijalankan ulang: `tests/browser.mjs`, `tests/static-site.mjs`, dan skrip npm di `package.json`. Log sesi tersedia di `/tmp/mythics-royal-ui.log`, `/tmp/mythics-royal-static.log`, dan `/tmp/mythics-royal-core.log`. Hasil mencakup skenario otomatis Chromium lokal, bukan seluruh kombinasi perangkat dan jaringan. Chromium pada host audit sesekali melaporkan `ERR_NETWORK_CHANGED`; pemulihan melalui tombol muat ulang ikut diuji.
