## Cara melanjutkan di PC lain

Dari checkout repo yang bersih:

```bash
git pull --ff-only origin main
npm ci
cat docs/HANDOFF-2026-10-02.md
npm run -s gemini:status
npm run -s gemini:next -- --agent claude --arah mundur
npm run -s gemini:verify -- batch-128
```

Perintah `next` untuk Claude sekarang kembali ke **batch-128**. Baca seluruh inbox dan laporan sebelum memperbaiki. Tidak ada entri yang belum dikirim; fokus pada error `azure-jay`, peringatan `tartalo-c12`, dan tinjauan editorial. Setelah ditangani, jalankan verifier dan `gemini:done`, lalu commit/push berkas batch itu sesuai alur agen.

**Penting untuk tahap sesudah 128:** `gemini:next` hanya memilih batch yang belum punya progres/inbox; ia tidak otomatis memilih batch berstatus `ditolak` atau `perlu-perbaikan`. Untuk mengulang 127→110 atau memperbaiki 141→138, cek kepemilikan terbaru, catat klaim batch yang dituju melalui helper progres yang ada, dan push klaimnya sebelum bekerja. Jangan mengira keluaran `next` adalah urutan penulisan ulang.

Jika yang meneruskan adalah agen selain Claude, catat pergantian pemilik batch secara eksplisit dan sinkronkan dengan PC lain. Hindari dua PC mengerjakan batch yang sama. Skrip sementara pembantu Claude di `/tmp` bukan prasyarat; semua JSON hasilnya sudah berada di inbox repo.
